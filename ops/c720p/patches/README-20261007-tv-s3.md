# C720P TV/Surround + S3 live fix

## Diagnosed live state

The current TV & surround component is `/opt/homeassistant/config/www/c720p-tv-surround.html`.

Its UI already calls:
- TV on/off through the Grundig control service.
- HTS on/off and volume through the S5 IR bridge.
- TV → HDMI 3 → HTS Bluetooth through the verified async pipeline.

The current failure is not button wiring. The S5 bridge health is offline/unreachable, so HTS/volume actions cannot complete until S5 rediscovery succeeds.

## Security LIVE S3 issue

`/opt/homeassistant/config/www/c720p-release/home-live-primary-v2.html` still explicitly contains:
- `FALLBACK_HEALTH`
- `FALLBACK_STREAM`
- an S3 live fallback
- an S3 still-image fallback

This must be replaced with a primary-camera-only v3 component. If the primary camera is unavailable, the UI should say "Primary camera offline"; it must not use S3.

## Intended button hardening

The TV & surround UI should:
1. Refresh real TV/HTS/IR/Bluetooth state before labeling buttons.
2. On HTS/volume taps, attempt S5 rediscovery/reconnect first when IR is offline.
3. Retry S5 recovery once.
4. Allow the verified surround pipeline to run even if direct S5 rediscovery fails, because it can succeed when HTS/Bluetooth is already reachable.
5. Never mark a command successful until the state endpoint confirms the resulting state.
