## Exact backend-to-Playback response protocol

Existing authenticated inner route: `GET /new/api/evidence-quality`. Only a `source_binding_status:"source_qualified_active_queue_only"` gap with exact original 3840×2160 three-frame evidence may be consumed. The separately integrated backend helper is `s9_anonymous_evidence_consumer_v361.consume(document,current,clip,appearance=None)` and **does not register a new public route**. It returns `(http_status:int, body:dict)`.

On **200**, `schema_version:"s9_anonymous_quality_consumption_v361"`; `ok:true`; canonical `clip_no`; `source_sha256`, `source_revision`, `model_sha256`, `evidence_revision_sha256` as 64-char lowercase hex; `source_bytes` integer; `analysis_version` string; `evidence_revision_scope:"clip_current_catalog_priority_queue_and_samples_v367"`; `source_binding_status:"revalidated_original_and_queue_at_consumption"`; `eligibility:"anonymous_quality_manual_review_only"`; `sample_count:3`; `sample_times_ms` array of three integer offsets **in milliseconds from clip start**; `sampled_face_candidate_count` integer 0–96; `observation` unreviewed candidate/no supported face in **three samples only**; `appearance_v3:"unavailable"|"provisional_not_admitted"`; and all identity/automatic person claims false, with human review required.

**400** = `invalid_clip` (not a canonical basename). **410** = `source_revision_or_evidence_revoked` (withdrawn priority, model/media/crop/queue source no longer current). **503** = `qualified_reader_unavailable` or `source_admission_unavailable` (unknown/missing/changed state). No error proves that a person is absent. Cached 200 results **never** grant eligibility on a future read; 410 invalidates downstream use immediately. When processing becomes completed, the target queue row legitimately changes its own revision once; unrelated queue updates do not. See `TASK9_ANONYMOUS_CONSUMER_V361.md` and `TASK9_EVIDENCE_BACKEND_API_CONTRACT_V359.md` for sanitized representative payloads.

V368 private queue remains `s9_priority_rescan_feedback_v304`. Tasks retain original SHA, byte size, media revision, native pass, detector model SHA, required analysis, status, attempts, deferrals, `next_attempt_at` and `lease_until` (UNIX seconds). Only reason-reclassified tasks additionally carry optional `legacy_source_key` 64 lowercase hex; it is internal audit provenance, **never** a browser person or identity identifier. States: `pending`, `processing`, `blocked`, `rejected`, `dead_letter`, `completed`. Three processing attempts, eight transient deferrals. Exact same-YuNet negative reason `same_yunet_model_cannot_validate_its_own_non_detection` remains unsupported/parked; does not become an automatic zero-person judgment.

Before starting any original-4K decode, the queue worker performs a bounded, read-only GET of `http://127.0.0.1:8795/new/api/evidence-quality` under its preexisting private loopback boundary. A currently running qualified V369 reader returns `gap_reader_contract:"s9_source_current_priority_reader_v369"` on a 200 response, even when it has no secondary report yet (`state:"not_yet_available"`). The worker **must not** begin a lease, spend an attempt, call the phone or decode video if that marker is missing, invalid, inaccessible or from an older in-memory handler. This is a capability and race guard, **not proof that real evidence was consumed**.
