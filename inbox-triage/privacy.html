Inbox Triage Agent Privacy Policy

Effective: 26 September 2026

Purpose

Inbox Triage Agent is a private email-assistance utility. It helps an authorized account owner review Gmail messages, identify messages that need attention, create concise summaries, prepare response suggestions, and apply configured processing labels or state changes.

Google user data accessed

When the account owner authorizes Gmail access, the utility may access email message content, headers, thread metadata, labels, sender and recipient information, and other Gmail data necessary to provide the requested inbox-triage functionality. The utility requests only the Gmail permissions configured for this purpose.

How Google user data is used

Google user data is used only to provide or improve the user-facing inbox-triage features requested by the account owner. This includes classifying messages, producing summaries, preparing reply suggestions, preventing duplicate processing, and applying configured Gmail labels or message state changes.

Storage and retention

Authentication credentials and operational state are stored on systems controlled by the account owner or operator. Message-derived working data is retained only for as long as needed for the configured triage workflow, reliability, duplicate protection, or troubleshooting. The service is designed to minimize unnecessary retention of Gmail content.

Sharing and disclosure

Google user data is not sold, rented, used for advertising, or shared with unrelated third parties. Data may be processed by infrastructure or AI services only when necessary to provide the requested triage function, subject to the operator's configured service providers and access controls.

Security

Access to the utility is restricted to authorized systems and account holders. OAuth credentials are stored with restricted permissions, and operational access is protected by private service controls.

User control and deletion

The account owner can revoke the application's Google access at any time from their Google Account permissions. Revoking access prevents new Gmail access. Locally stored OAuth credentials and retained operational data can also be deleted from the systems running the utility.

Google API Services User Data Policy

Inbox Triage Agent's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

This policy may be updated when the utility's data practices materially change. The current version will remain available at this URL.
