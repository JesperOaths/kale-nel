Inbox Triage Agent

Inbox Triage Agent is a private email-assistance utility used to review authorized Gmail inboxes, identify messages that need attention, produce concise summaries, and prepare response suggestions for the account owner.

How it uses Google account data

The utility requests Gmail access only after the Google account owner explicitly authorizes it. Gmail data is used only to perform inbox triage, prepare summaries or reply suggestions, and mark messages as processed when the owner has configured that behavior.

Google user data is not sold, used for advertising, or shared with unrelated third parties. Access is limited to the functionality requested by the account owner.

Privacy

For details about access, use, retention, and deletion of Google user data, read the Inbox Triage Agent Privacy Policy.

This utility is operated as a private Kalenel service and is not offered as a public email product.
