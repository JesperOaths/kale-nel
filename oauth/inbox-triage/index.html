Inbox Triage Agent

Inbox Triage Agent is a private email-assistance service used by its account owners. It reads configured Gmail inboxes, identifies messages that need attention, prepares concise digests and optional reply suggestions, and marks successfully processed messages so they are not handled twice.

The service requests only the Gmail permission needed for that workflow. It does not provide public mailbox access and it does not sell user data.

How Gmail data is used

Message metadata and content are accessed only to perform the requested inbox-triage workflow. Processing can use configured AI providers to produce summaries or reply suggestions; when those providers are unavailable, processing may be deferred or use a local deterministic fallback. Selected digest output can be delivered to the account owner's configured private Signal destination.

Data controls

OAuth credentials are kept by the private service and are not published on this website. Users can revoke Google access at any time from their Google Account permissions.
