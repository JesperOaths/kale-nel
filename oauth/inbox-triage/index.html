Inbox Triage Agent

Inbox Triage Agent is a private Kalenel productivity utility for specifically authorized account owners. It monitors configured Gmail inboxes, identifies messages that need attention, prepares concise digests and optional reply suggestions, and marks successfully processed mail so the same item is not handled repeatedly.

It is not a public mailbox service and it does not provide access to anyone else's Gmail account. Google access occurs only after the Google account owner completes Google's OAuth consent flow.

Why Google access is requested

The application requests the restricted Gmail scope https://www.googleapis.com/auth/gmail.modify. The workflow needs to read message content and metadata in order to determine what requires attention and also needs to update Gmail labels or processing state after successful handling. A read-only Gmail scope would not allow that label/state update, while label-only or metadata-only scopes would not provide the message content needed for summaries.

How Gmail data is used

  • Read new or relevant messages, headers, thread state and labels for inbox triage.
  • Create user-requested summaries and optional reply suggestions.
  • Apply or update the configured processed label/state after successful processing.
  • Prevent duplicate processing and recover safely from interrupted runs.
  • Deliver selected digest output to the account owner's configured private destination.

When AI-assisted summarization is enabled by the account owner, relevant message content may be sent to configured processing providers solely to provide that user-facing feature. Google Workspace data is not used to train, develop or improve generalized/non-personalized AI or machine-learning models.

Google Limited Use disclosure. Inbox Triage Agent's use and transfer of information received from Google Workspace APIs adheres to the Google User Data Policy, including the Limited Use requirements.

User control

Users can revoke the application's Google access at any time from their Google Account connections/security settings. Revocation prevents future Gmail API access. Local authorization credentials and retained operational state can also be deleted on request.
