Privacy Policy

Effective and last updated: 26 September 2026

This Privacy Policy explains how the Kalenel Inbox Triage Agent accesses, uses, stores, transfers and deletes Google user data. The service is a private productivity utility for specifically authorized account owners.

Google user data accessed

The application uses the Gmail API with https://www.googleapis.com/auth/gmail.modify. Depending on the messages being processed, this can include message and thread identifiers, sender and recipient information, subject lines, headers, message bodies, timestamps, thread state, attachment metadata where present, and Gmail labels. The application may also modify labels or processing state after successful handling.

Purposes of use

Google user data is used only to provide the user-directed inbox-triage workflow: identifying new or relevant messages, preparing summaries and optional reply suggestions, determining whether a message still needs attention, applying the configured processed state or label, preventing duplicate processing, recovering interrupted deliveries and delivering selected digest output to the account owner's configured private destination.

AI-assisted processing

When enabled by the account owner, message content necessary for the requested summary or reply-suggestion feature may be transferred to configured AI processing providers, currently including OpenAI and a configured Google Gemini fallback, solely to provide that user-facing functionality. If cloud processing is unavailable, work may be deferred or handled by a local deterministic fallback.

Google Workspace API data is not used to create, train, develop or improve generalized or non-personalized artificial-intelligence or machine-learning models. It is not used for advertising, profiling for advertising, credit decisions, lending, data brokerage or surveillance.

Storage and retention

OAuth credentials are stored in the private service environment with restricted access. The service may retain operational information such as message identifiers, timestamps, processing status, generated digest/reply text, retry state and delivery status when needed to operate the workflow, avoid duplicate processing, recover interrupted work or diagnose failures. Google message content is not intentionally retained as a general-purpose archive by this application.

Operational data is kept only for as long as reasonably necessary for those functions and is removed or aged out under the service's maintenance and retention processes. OAuth credentials are retained until they are revoked, replaced or deleted.

Sharing and transfers

Google user data is not sold, rented or shared for unrelated purposes. Transfers occur only when needed to provide the user-directed feature, such as to the configured AI-processing provider for generation of a requested summary/reply suggestion or to the account owner's configured private delivery destination. Service operators do not routinely read Gmail content; human access is limited to circumstances permitted by Google policy, such as explicit user request, security investigation or legal obligation.

Security

The service uses OAuth rather than storing Google account passwords. Credentials and service state are kept in a private host environment and are not exposed by this public website. Access to operational systems is restricted and the service is designed to avoid unnecessary duplication of Google user data.

User choices, revocation and deletion

Users may revoke Google authorization at any time from their Google Account's third-party connections or security settings. Revocation prevents new Gmail API access. Users may also request deletion of locally retained OAuth credentials and service state. Detailed instructions are available on the data deletion and revocation page.

Google API Services / Workspace Limited Use

Inbox Triage Agent's use and transfer of information received from Google Workspace APIs adheres to the Google User Data Policy, including the Limited Use requirements.

Children

This private administrative/productivity utility is not directed to children and is not offered as a consumer service for minors.

Changes

If the service materially changes how it accesses, uses, stores or shares Google user data, this policy will be updated before the changed practice is used. Where required, affected users will be asked to consent again.

Contact

Privacy, access or deletion questions may be sent to prutsalberts@gmail.com.
