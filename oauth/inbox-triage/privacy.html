Privacy Policy

Effective 26 September 2026

This policy describes how Inbox Triage Agent handles Google user data for the private account owners who authorize it.

Google data accessed

The service uses the Google Gmail API with the configured Gmail modification scope. It may access message headers, sender and recipient information, subject lines, message bodies, thread state, and Gmail labels as needed to triage messages and mark completed processing.

How data is used

Google user data is used only to provide inbox triage: detecting relevant new mail, creating concise summaries and reply suggestions, preventing duplicate processing, applying the configured processed state or label, and delivering selected digest output to the user's configured private destination.

AI processing

When enabled by the account owner, relevant message content may be sent to configured AI processing providers, including OpenAI and a configured fallback provider, solely to generate the requested summaries or reply suggestions. If cloud processing is unavailable, work may be deferred or handled by a local deterministic fallback.

Storage and security

OAuth credentials and service state are stored in the private service environment and are not exposed by this website. Operational state is retained only as needed to run the workflow, prevent duplicate processing, recover interrupted deliveries, and diagnose failures. Access is limited to the account owners and service components required to provide the workflow.

Sharing, sale, and advertising

Google user data is not sold, rented, used for advertising, or shared for unrelated purposes. Data is disclosed only to processors required to provide the configured workflow, such as the selected AI-processing provider and the account owner's configured delivery destination.

Revocation and deletion

Users may revoke the application's Google access from their Google Account security/connection settings. Revoking access prevents future Gmail API access. Account owners may also remove locally stored authorization credentials and service state from the private host.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy may be sent to the developer/support email shown on the application's Google OAuth consent screen.
