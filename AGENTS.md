# Repository operation guidance

For authorized work on this repository or its connected C720P, websites, security cameras, Home Assistant, and Android devices, **read `ops/c720p/ADMIN_ACCESS_CONTINUITY.md` first**. That runbook records validated remote-management architecture, audit references, and fallback rules.

Prioritize autonomous, proactive and thorough task execution. Discover and use the connected GitHub/Supabase/other provider capabilities first; do not confuse a missing direct SSH terminal in one chat with an unavailable C720P outbound maintenance agent. Check the private Supabase operator runbook through an authorized management connection for the exact current gateway. Never represent an untested route as verified.

Preserve at least one tested administrator pathway across security changes. Back up, stage, verify and retain rollback. Avoid disclosing secrets or opening unauthenticated device-control endpoints. Escalate to the owner as a last resort after available authorized options are exhausted.
